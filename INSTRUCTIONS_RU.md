# Инструкция по запуску AI-OCR и Демо-стенда «Майская прогулка»

Этот документ содержит руководство по развертыванию, запуску и тестированию системы оптического распознавания рукописно-печатных анкет (OCR) и веб-интерфейса волонтёра для «Майской прогулки».

---

## 1. Подготовка окружения

### Требования:
* Python 3.10+ (проверено на Python 3.12)
* Установленный пакетный менеджер `pip`

### Установка зависимостей:
Выполните в корне репозитория:
```bash
pip install opencv-python onnxruntime rapidocr-onnxruntime numpy pillow fastapi uvicorn python-multipart
```

---

## 2. Структура системы

* `ocr_system/` — ядро системы OCR:
  * `form_generator.py` — генератор машиночитаемого бланка анкеты с ArUco-маркерами и ячейками под буквы.
  * `event_config.json` — конфигурация сезона (год проведения, дата, список и километраж дистанций).
  * `aligner.py` — выравнивание геометрии листа к `1200×1600` (ArUco-маркеры, 4 чёрных угловых квадрата для старых бланков, внешний контур листа).
  * `classifier.py` — гибридный классификатор на базе трёх ONNX-моделей:
    * `models/pp_v6_medium/` (`PP-OCRv6 Medium Cyrillic`) — строковое распознавание кириллицы и e-mail;
    * `models/handwritten_char.onnx` + `handwritten_dict.txt` (дообученная на `CoMNIST` + `MNIST` + шрифтах) — поклеточное распознавание рукописных цифр, сложных букв кириллицы и символов e-mail с маскированием алфавита;
    * базовая латинская модель `RapidOCR` для `@` и латинских доменов.
  * `validator.py` — постобработка: честная валидация дат (`DD.MM.YYYY`), расчёт возраста относительно года прогулки, форматирование телефона `+7 (XXX) XXX-XX-XX`.
  * `pipeline.py` — единый конвейер: динамический поиск строк по меткам бланка, локальный OMR-анализ чекбоксов дистанции и пола, поклеточное извлечение ячеек без рамок.
  * `mock_filler.py` — генератор реалистичных заполненных ArUco-анкет с шумом и перспективным наклоном для тестирования.
* `web_app.py` — интерактивный веб-сервер (FastAPI) и рабочее место волонтёра регистрации.
* `test_user_photo.py` — тест на реальном фото классического бланка с 4 угловыми квадратами.
* `test_pipeline.py` — базовый тест распознавания ArUco-бланка.
* `test_batch.py` — пакетный тест на нескольких анкетах с разными полами, городами и дистанциями.
* `test_multiyear.py` — тест корректной работы системы для разных годов проведения (2026, 2027, 2028, 2030+).

## 3. Запуск интерактивного Демо-стенда (Web App)

Веб-приложение имитирует рабочее место волонтёра на выдаче карт в стартовом городке.

### Команда запуска:
```bash
python web_app.py
```

После запуска откройте в браузере:
👉 **http://127.0.0.1:8080** (порт можно задать переменной `PORT`).

### Что можно делать в интерфейсе:
1. **Загружать свои фотографии**: нажмите *«📁 1. Выбрать фото анкеты»*, выберите фото старого или нового бланка, затем нажмите *«⚡ 2. Распознать анкету»*.
2. **Проверять готовые образцы**: пресеты *«Реальное фото»*, *«Образец 1 (Иванов)»*, *«Образец 2 (Смирнов)»* загружают бланк в превью и прогоняют реальный OCR-пайплайн.
3. **Сверка волонтёром**: система выводит статус `APPROVED` (зелёный) или `REQUIRES_REVIEW` (жёлтый), дистанцию (OMR), пол (OMR), возраст, телефон, e-mail, город, число предыдущих участий (без ведущего нуля) и номер карты (если заполнен в блоке `№ КАРТЫ:`).

## 5. Генерация чистого бланка и настройка нового сезона

```bash
python -m ocr_system.form_generator
```
Файл сохранится в `ocr_system/sample_form_template.png`. Для смены года, даты и дистанций отредактируйте `ocr_system/event_config.json`.
