# Инструкция по запуску AI-OCR и Демо-стенда «Майская прогулка»

Этот документ содержит руководство по развертыванию, запуску и тестированию системы оптического распознавания рукописно-печатных анкет (OCR) и веб-интерфейса волонтера для «Майской прогулки».

---

## 1. Подготовка окружения

### Требования:
* Python 3.10+ (проверено на Python 3.12)
* Установленный пакетный менеджер `pip`

### Установка зависимостей:
Выполните в корне репозитория:
```bash
pip install opencv-python onnxruntime numpy pillow fastapi uvicorn python-multipart
```

---

## 2. Структура системы

* `ocr_system/` — ядро системы OCR:
  * `form_generator.py` — генератор машиночитаемого бланка анкеты с угловыми метками и ячейками под буквы.
  * `event_config.json` — конфигурация сезона (год проведения, дата, список и километраж дистанций).
  * `aligner.py` — модуль выравнивания геометрии листа по 4 опорным реперным точкам (Homography).
  * `extractor.py` — сегментатор ячеек (коробочек) и OMR-отметок (дистанция и пол).
  * `classifier.py` — модель распознавания печатных кириллических букв и цифр (точность >95–99%).
  * `validator.py` — постобработка: валидация дат, вычисление возраста относительно года прогулки, автоисправление городов Свердловской области и форматирование телефона.
  * `pipeline.py` — единый конвейер распознавания бланка.
  * `mock_filler.py` — генератор реалистичных заполненных анкет с шумом и наклоном для тестирования.
* `web_app.py` — интерактивный веб-сервер и рабочее место волонтера регистрации.
* `test_pipeline.py` — базовый тест распознавания одного бланка.
* `test_batch.py` — пакетный тест на нескольких анкетах с замером точности.
* `test_multiyear.py` — тест корректной работы системы для разных годов проведения (2026, 2027, 2028, 2030+).

## 3. Запуск интерактивного Демо-стенда (Web App)

Веб-приложение имитирует реальное рабочее место волонтера на выдаче карт в стартовом городке.

### Команда запуска:
```bash
python web_app.py
```

После запуска откройте в браузере:
👉 **[http://127.0.0.1:8080](http://127.0.0.1:8080)** (или порт 8000, если он свободен).

### Что можно делать в демке:
1. **Переключать тестовые бланки**: кнопки *«Анкета 1 (Иванов)»*, *«Анкета 2 (Смирнов)»*, *«Анкета 3 (Петрова)»* показывают работу алгоритма с разными почерками, городами и дистанциями.
2. **Загружать свои фотографии**: нажмите *«Загрузить / Сфотографировать бланк»* и выберите любое фото бланка.
3. **Оценить скорость**: полный цикл (выравнивание + OMR + OCR всех полей) занимает **~150 миллисекунд**.
4. **Сверка в 1 клик**: волонтер видит статус `APPROVED` (зеленый) или сомнительные поля (желтый) и нажимает кнопку выдачи карты.

## 4. Консольное тестирование и проверка точности модели

### Запуск базового теста (1 анкета):
```bash
python test_pipeline.py
```
*Выведет статус распознавания, точность (Confidence), ФИО, дату рождения, телефон, город и номер карты.*

### Запуск пакетного теста точности (Batch Test):
```bash
python test_batch.py
```
*Демонстрирует точность распознавания на наборе анкет с имитацией перспективных искажений от съемки со смартфона.*

### Запуск теста мульти-сезонности (разные года):
```bash
python test_multiyear.py
```
*Показывает, как система динамически адаптируется под разные года (2026, 2027, 2028 гг.), пересчитывая возраст участников и актуальные маршруты без правок кода.*

## 5. Генерация чистого бланка для печати

Если вам необходимо сгенерировать PDF/PNG оригинал бланка анкеты с ячейками под печать в типографии:
```bash
python -m ocr_system.form_generator
```
Файл бланка высокого разрешения будет сохранен в:
`ocr_system/sample_form_template.png`

## 6. Как настроить новый сезон проведения

Чтобы перевести систему на следующий год:
1. Откройте файл `ocr_system/event_config.json`.
2. Измените год, дату и список дистанций:
   ```json
   {
     "year": 2027,
     "event_date": "2027-05-16",
     "event_date_display": "16 мая 2027 г.",
     "distances": [
       {"id": "d1", "label": "50 км (Классика)"},
       {"id": "d2", "label": "35 км (Юбилейный)"},
       {"id": "d3", "label": "20 км (Озерный)"},
       {"id": "d4", "label": "10 км (Семейный)"}
     ]
   }
   ```
3. Сгенерируйте новые бланки командой `python -m ocr_system.form_generator`.
Система автоматически подхватит конфигурацию для оцифровки.
