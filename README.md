# Сайт и система регистрации "Майской прогулки"

```bash
# Запуск API-сервиса
uv run fastapi dev
# Для запуска случайного файла
uv run <файл>
# Для добавления библиотеки
uv add <библиотека>
```

`src\` - модули бэкенда.

`frontend\` - фронтенд.

`src\mayprogulka\openapi.json` - структура API.

`src\mayprogulka\entrypoint.py` - вход в бэкенд-приложение.
