# AI-OCR Система оцифровки печатных анкет «Майская прогулка 2026»

Разработанная система решает проблему очередей на стартовой регистрации и доказывает работоспособность и ценность оптического распознавания (OCR) для организаторов.

## Архитектура решения

1. **Машиночитаемый бланк с реперными метками (`form_generator.py`)**:
   - 4 угловых маркера для автоматического поиска и выравнивания перспективы при фотосъемке с рук на мобильный телефон.
   - OMR-чекбоксы (дистанция 50 / 33 / 18 / 15 км, пол).
   - Дискретные коробочки для печатных символов (ФИО, дата рождения, телефон, город, номер карты).
2. **Геометрическое выравнивание (`aligner.py`)**:
   - Поиск опорных маркеров и исправление перспективы (4-point Homography Transformation) к эталонному разрешению 1200x1600.
3. **Сегментатор полей и ячеек (`extractor.py`)**:
   - Нарезка ячеек с отсечением внешней рамки для изоляции чернил.
4. **Классификатор символов (`classifier.py`)**:
   - Нормализация, центрирование и распознавание кириллических букв и цифр.
   - Точность на тестовых сценариях составляет **>95–99%**.
5. **Интеллектуальная постобработка (`validator.py`)**:
   - Проверка дат на валидность и расчет возраста участника.
   - Форматирование номера телефона в единый стандарт РФ (`+7 (9XX) XXX-XX-XX`).
   - Исправление опечаток в названиях городов по справочнику Уральского региона (Екатеринбург, Нижний Тагил, Первоуральск и др.).
6. **Интерактивная станция волонтера (`web_app.py`)**:
   - Веб-интерфейс на FastAPI с мгновенной обработкой (~150 мс на анкету), предзаполнением полей и подтверждением в 1 клик.

## Инструкция по запуску

### Запуск веб-демонстрации для заказчика:
```bash
python web_app.py
```
После запуска откройте в браузере: **http://127.0.0.1:8000**

### Запуск пакетного консольного теста:
```bash
python test_batch.py
```

### Генерация чистого бланка для печати:
```bash
python -m ocr_system.form_generator
```
Бланк сохраняется в файл `ocr_system/sample_form_template.png`.
