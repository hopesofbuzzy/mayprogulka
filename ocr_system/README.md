# AI-OCR Система оцифровки печатных и рукописных анкет «Майская прогулка»

Система автоматизирует оцифровку бумажных анкет участников на стартовой регистрации. Поддерживает **как новые машиночитаемые бланки с ArUco-маркерами, так и старые/классические бланки с 4 чёрными угловыми квадратами** (а также выравнивание по внешнему контуру листа и плотно обрезанные фото бланка).

---

## 1. Где достать бланки

1. **Новый машиночитаемый бланк (с ArUco-маркерами `DICT_4X4_50`)**:
   - Сгенерировать чистый шаблон для печати:
     ```bash
     python -m ocr_system.form_generator
     ```
     Файл сохранится в `ocr_system/sample_form_template.png` (параметры мероприятия и года берутся из `ocr_system/event_config.json`).
   - Сгенерировать тестовый заполненный бланк (для проверки пайплайна):
     используйте `create_filled_sample(...)` из `ocr_system/mock_filler.py` (пример есть в `test_batch.py` и `test_multiyear.py`).
2. **Старые / классические бланки**:
   - Используются бумажные анкеты с 4 чёрными реперными квадратами по углам (поддерживаются фото любого разрешения — от сканов до снимков 12 Мп со смартфона).
   - Пример реального фото анкеты и результатов выравнивания: `test_user_photo.py`, `ocr_system/user_real_aligned.png`.

---

## 2. Архитектура распознавания (без фиктивных подмен)

1. **Выравнивание перспективы (`ocr_system/aligner.py`, `DocumentAligner`)** к единому холсту `1200×1600`:
   - **Новые бланки** — по 4 ArUco-маркерам в углах (`ID 0..3`).
   - **Старые бланки** — по 4 чёрным угловым квадратам (`_align_black_squares` с адаптацией площади под разрешение кадра и несколькими порогами яркости).
   - **Резервные стратегии** — по внешнему контуру листа бумаги (`_align_document_contour`) или проверке ключевых слов бланка на плотно обрезанных фото.

2. **Динамическая привязка строк и OMR (`ocr_system/pipeline.py`, `FormOCRPipeline`)**:
   - Поиск строк полей по печатным подписям слева (`_detect_row_anchors`), что работает на обоих шаблонах без жёсткой привязки к пикселям одного бланка.
   - Локальный OMR-анализ чекбоксов дистанции и пола (`_extract_distance`, `_extract_gender`) с компенсацией теней и неравномерного освещения.
   - Поклеточная сегментация (`_find_boxes_in_row`, `_extract_clean_cells`) — вырезает содержимое каждой коробочки без серой рамки и нижней риски, отбрасывает пустые ячейки.

3. **Гибрид из трёх ONNX-моделей (`ocr_system/classifier.py`, `DeepLearningOCRClassifier`)**:
   - **`PP-OCRv6 Medium Cyrillic`** (`ocr_system/models/pp_v6_medium/inference.onnx`) — строковый контекст для кириллических полей (`ФАМИЛИЯ`, `ИМЯ`, `ОТЧЕСТВО`, `ГОРОД`) и e-mail.
   - **Дообученная `HandwrittenBoxNet`** (`ocr_system/models/handwritten_char.onnx` + `handwritten_dict.txt`, 73 класса: кириллица `А–Я, Ё`, латиница `A–Z`, цифры `0–9`, символы `-.@_`; обучена на `CoMNIST` + `MNIST` + шрифтовых аугментациях с маскированием алфавита под тип поля) — для рукописных цифр (`ДАТА РОЖД.`, `ТЕЛЕФОН`, `РАНЕЕ УЧАСТИЙ`, `№ КАРТЫ`), уточнения сложных рукописных букв кириллицы (например, треугольной `Д`) и символов e-mail.
   - **Базовая латинская модель `RapidOCR`** — для распознавания `@` и латинских доменов в e-mail.

4. **Честная валидация (`ocr_system/validator.py`, `PostValidator`)**:
   - Проверка и форматирование даты рождения (`DD.MM.YYYY`, поддержка 8-значного слитного вывода `DDMMYYYY`), расчёт возраста на год мероприятия, форматирование телефона `+7 (XXX) XXX-XX-XX`.
   - Количество предыдущих участий выводится без ведущего нуля (`5`, `0`, `12`).
   - Номер карты читается непосредственно из ячеек `№ КАРТЫ:` (если не заполнен — остаётся пустым).

### Настройка под новый год / мероприятие
Отредактируйте `ocr_system/event_config.json` (название, `year`, `event_date`, список `distances`) или передайте `override_year` в `pipeline.process_image(img, override_year=2027)`.

## 3. Быстрый запуск и тестирование

### Установка зависимостей
```bash
pip install opencv-python onnxruntime rapidocr-onnxruntime numpy pillow fastapi uvicorn python-multipart
```

### Интеграция в код (Python)
```python
import cv2
from ocr_system.pipeline import FormOCRPipeline

img = cv2.imread("path/to/form.jpg")
pipeline = FormOCRPipeline()
result = pipeline.process_image(img)
print(result["data"])
```

### Запуск веб-демонстрации (FastAPI)
```bash
python web_app.py
```
После запуска откройте в браузере: **http://127.0.0.1:8080** (порт можно переопределить через переменную окружения `PORT`).

### Тесты
- Проверка на реальном фото старого бланка:
  ```bash
  python test_user_photo.py
  ```
- Проверка базового ArUco-образца:
  ```bash
  python test_pipeline.py
  ```
- Проверка мультисезонности (разные годы проведения):
  ```bash
  python test_multiyear.py
  ```
- Пакетный тест на нескольких анкетах:
  ```bash
  python test_batch.py
  ```
