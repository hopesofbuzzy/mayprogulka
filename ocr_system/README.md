# AI-OCR Система оцифровки печатных анкет «Майская прогулка»

Разработанная система решает проблему очередей на стартовой регистрации и автоматизирует оцифровку бумажных анкет. Поддерживает **как новые бланки с ArUco-маркерами, так и старые/классические бланки с 4 чёрными угловыми квадратами** (а также обычный лист по внешнему контуру).

---

## 1. Где достать бланки

1. **Новый машиночитаемый бланк (с ArUco-маркерами `DICT_4X4_50`)**:
   - Сгенерировать чистый шаблон для печати:
     ```bash
     python -m ocr_system.form_generator
     ```
     Файл сохранится в `ocr_system/sample_form_template.png` (параметры мероприятия и года берутся из `ocr_system/event_config.json`).
   - Сгенерировать тестовый заполненный бланк (для проверки пайплайна):
     используйте `create_filled_sample(...)` из `ocr_system/mock_filler.py` (пример есть в `test_multiyear.py`).
2. **Старые / классические бланки**:
   - Используются бумажные анкеты с 4 чёрными реперными квадратами по углам (или обычные сканы/фото листа целиком).
   - Пример реального фото анкеты и результатов выравнивания: `test_user_photo.py`, `ocr_system/user_real_aligned.png`.

---

## 2. Как работать с бланками (поддерживаемые форматы)

Модуль `DocumentAligner` (`ocr_system/aligner.py`) автоматически выбирает стратегию выравнивания к единому шаблону `1200×1600`:
1. **Новые бланки** — по 4 ArUco-маркерам в углах (`ID 0..3`).
2. **Старые бланки** — по 4 чёрным угловым квадратам (`_align_black_squares`).
3. **Запасной вариант** — по внешнему контуру листа бумаги (CamScanner-подход, если угловые метки не найдены).

Далее `FormOCRPipeline` (`ocr_system/pipeline.py`) выполняет:
- извлечение OMR-чекбоксов (дистанция, пол);
- нарезку и распознавание текстовых полей (`PP-OCRv6 Medium Cyrillic` в `classifier.py`);
- постобработку и валидацию в `validator.py` (дата рождения, расчёт возраста на год проведения, формат телефона `+7 (9XX) XXX-XX-XX`, исправление опечаток в городах Уральского региона).

### Настройка под новый год / мероприятие
Отредактируйте `ocr_system/event_config.json` (название, `year`, `event_date`, список `distances`) или передайте `override_year` в `pipeline.process_image(img, override_year=2027)`.

## 3. Быстрый запуск и тестирование

### Интеграция в код (Python)
```python
import cv2
from ocr_system.pipeline import FormOCRPipeline

img = cv2.imread("path/to/form.jpg")
pipeline = FormOCRPipeline()
result = pipeline.process_image(img)
print(result["data"])
```

### Запуск веб-демонстрации (FastAPI)
```bash
python web_app.py
```
После запуска откройте в браузере: **http://127.0.0.1:8000**

### Тесты
- Проверка на реальном фото анкеты:
  ```bash
  python test_user_photo.py
  ```
- Проверка мультисезонности (разные годы проведения):
  ```bash
  python test_multiyear.py
  ```
- Пакетный тест:
  ```bash
  python test_batch.py
  ```
